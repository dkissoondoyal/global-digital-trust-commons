# Changelog

## [0.1.0] — 2026-10-30 (source publication preparation)

- Bilingual (English/French) fictional self-assessment demonstration.
- Illustrative email settings (SPF, DKIM, DMARC), permission patterns and recovery ownership.
- Six observations in the default synthetic scenario.
- Local in-browser JSON export and printable report.
- WordPress password-gated demonstration plugin for the pilot page `adtc-pilot`.
- No account integrations, remote scans, external API calls or server-side storage of responses.
- Initial public development documentation and reproducible tests.

**Evidence boundary:** Private pilot activation and English/French functional testing were reported by the project organiser; there are no confirmed independent external pilot results or security audit results in this release.
