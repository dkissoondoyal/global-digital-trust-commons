## ADTC and GDTC programme roles

- **GDTC:** global commons, shared software, common security and governance framework.
- **ADTC:** the Africa-focused pilot and regional co-design programme using the GDTC common codebase.
- See [ADTC Africa pilot charter](ADTC_AFRICA_PILOT.md). No separate regional code fork is planned at this stage.

## Proposed phases (not funded commitments)

**2026–early 2027:** Refine technical documentation and threat model, recruit consenting reviewers, correct reported bugs, and ensure accessibility.

**2027 Q1–Q2:** Pilot a local-first permissions register; define evidence provenance and an explicitly authorised email-domain baseline. Keep collection minimal.

**2027 Q3–Q4:** Independent technical review, reproducible tests, consent-based usability pilots, optional data-free language evaluation. Maintain public issue log.

**2028:** Optional local change records, improved docs and translation support, v1 release if appropriately reviewed, and an initial community governance plan.

**Global reach:** Initial work originates in Mauritius and is tested first in Africa. Future participation may include volunteers from five ICANN At-Large geographical regions, but no RALO or ALS affiliation should be represented as project sponsorship or commitment without written confirmation. Language support beyond English/French is aspirational.

The fellowship proposal and budget are **not** the same thing as awarded funding. Dates are planning assumptions and may change.
