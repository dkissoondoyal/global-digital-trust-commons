# GDTC v0.2 CI and release gates

The workflow `.github/workflows/gdtc-v02-tests.yml` is configured to execute **the exact committed branch files** on pull requests affecting the experimental prototype and on manual dispatch. It runs Python unit tests, Node integration tests and a synthetic command-line JSON evidence check.

**Status: configured, not yet verified as a successful GitHub Actions run.** Do not represent the existence of a workflow as a passing CI result.

## Manual review gates
- Verify GitHub Actions result on the draft pull request; investigate failures.
- In a current browser, import a JSON file generated by `scripts/assess_http_headers.py`; verify EN/FR rendering, invalid-file handling, keyboard navigation and focus indicators.
- Confirm no background network calls and no persistence or upload of report content.
- Review untrusted-input rendering, input limits, provenance, privacy, security and accessibility.
- Obtain maintainer approval before merging; independent review and NGO pilot are separate later stages.

The workflow performs no network scanning of targets, and does not deploy any WordPress plugin.
